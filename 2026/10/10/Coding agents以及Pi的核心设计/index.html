Coding agents以及Pi的核心设计

Posted on 2026-10-10 In Anything , 11-768: AI Agents
关于Pi...

最近阅读了腾讯团队写的一篇关于Coding agents的文章（文章AI味比较重，但是对4个比较有代表性的Coding agents的概述和图解做的不错），刚好也在学习CMU 11-768，对Agents/Coding agents有了更系统的理解（后面希望有时间梳理一下）.

可以将Agents所需的基础能力概括为4类：

  • Tool Use.
  • Context Management.
  • Skills and Memory.
  • Planning, Task Decomposition, and Multi-Agent Coordination.

可以看到，几个Coding agents的核心设计都有体现上述4种能力.

下面以Pi为例，简要整理一下4种能力的具体实现.

Pi features

Site: here

有什么：

  • 仅内置4种工具：read、write、edit、bash（最新版本支持MCP），支持自定义工具（通过Extensions）.
  • 上下文管理：
    • 支持可定制的System prompt（SYSTEM.md、AGENTS.md、Dynamic context for extensions）.
    • 支持可定制的Compaction（通过Extensions）.
    • 支持Steer/Follow-up.
    • 使用树管理会话上下文，同时支持导出、分享、可视化.
  • 支持Skills，支持自定义记忆系统（通过Extensions）.
  • 生态：
    • 支持5种模式：interactive、print、json、rpc、sdk.
    • 通过Extensions、Skills、Prompt templates、Themes，可灵活扩展和定制.

      Extensions are TypeScript modules with access to tools, commands, keyboard shortcuts, events, and the full TUI.

    • 可以自己构建、让Pi构建、分享自己构建或安装他人构建的上述扩展.
